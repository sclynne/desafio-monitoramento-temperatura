# desafio-monitoramento-temperatura
Projeto em linguagem C para monitoramento de temperaturas utilizando while e do...while.

Aluna: Suellen Carolynne Queiroz dos Santos
Disciplina: Algoritmos e Pensamento Computacionail
Professora: Karla Sartin
Título do projeto: Sistema de Monitoramento Industrial em C

O objetivo é criar, em linguagem C, um sistema de monitoramento de temperatura que registre leituras, identifique valores acima do limite e encerre após três temperaturas consecutivas acima desse valor.

Como funciona o programa:
O usuário informa o limite e depois registra as temperaturas.
O programa valida as entradas, calcula média, maior e menor temperatura e conta quantas leituras ficaram acima do limite.
Se uma temperatura ficar dentro do limite, a contagem consecutiva é reiniciada. O programa encerra após três leituras consecutivas acima do limite.

Estruturas ultilizadas 
Foi utilizado `do...while` para validar o limite e `while` para realizar o monitoramento até ocorrerem três temperaturas consecutivas acima do limite.
